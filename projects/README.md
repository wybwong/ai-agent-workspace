# 项目追踪目录说明

每个项目在此目录下创建一个子目录，用于追踪项目状态、决策和进度。

## 使用方式

接到新项目时执行：
```
mkdir projects/<project-name>
# 复制模板内容创建 README.md
```

## 目录结构

```
projects/
├── README.md          # 本文件（说明）
└── <project-name>/
    └── README.md      # 项目追踪文件
```

## 项目追踪文件模板

```markdown
# 项目名称

## 基本信息
- 客户：
- 开始日期：
- 预计交付：
- 部署方式：

## 需求概述
（一句话描述）

## MVP 功能清单
- [ ] 功能1
- [ ] 功能2

## 技术决策
- 前端：Vue 3 + Vite + Element UI Plus
- 接口：
- 部署：

## 当前状态
- 进行中 / 已完成 / 已交付

## 重要节点
- YYYY-MM-DD：xxx

## 遗留问题 / 待确认
-
```
