# Projects

Track each real project under its own folder:

```text
projects/
└── <project-name>/
    └── README.md
```

Each project README should capture:

- what the project is
- current status
- stack and runtime
- build, test, and deploy commands
- important decisions
- open questions

Create a new project folder with:

```bash
bash scripts/new-project.sh <project-name>
```
